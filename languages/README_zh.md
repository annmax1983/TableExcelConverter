一款轻量级浏览器扩展，一键提取网页HTML表格并导出为CSV文件。

> Chromium 内核 · Manifest V3 · 最小权限 · 本地处理

---

## 为什么选择 TableGrab？

从政府网站、统计平台、行业数据页复制表格，结果格式错乱？TableGrab 直接读取 HTML 表格结构，导出干净的 CSV 数据——零复制错误，零格式丢失。

| 优势 | 说明 |
|------|------|
| 📊 **自动识别** | 扫描页面所有 HTML 表格，显示行×列数 |
| 🔗 **合并单元格** | 正确处理 rowspan/colspan，保留表格结构 |
| 📦 **批量导出** | 单表/多选/全表一键导出 |
| 🔤 **无乱码** | UTF-8 BOM 编码修复中文乱码 |
| ⚡ **一键操作** | 即时下载，无需刷新页面 |
| 🔒 **隐私安全** | 权限精简，表格数据永不上传 |

## 安装方法

1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 开启**开发者模式**
3. 点击**加载已解压的扩展程序**，选择项目文件夹

---

## 使用方法

1. 访问任何含 HTML 表格的网页
2. 点击 **TableGrab** 图标
3. 表格自动识别，显示行×列信息
4. 悬停高亮，勾选要导出的表格
5. 点击**导出全部**或**导出选中**
6. CSV 文件自动下载

---

## 已知限制

- 仅支持 HTML `<table>` 元素——图片表格、Canvas 表格、虚拟 JS 表格无法识别
- 跨域 iframe 表格无法访问（浏览器安全限制）
- 复杂动态加密表格可能无法解析
