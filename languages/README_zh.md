## 为什么选择 TableGrab？

从政府网站、统计平台、行业数据页复制表格，结果格式错乱？TableGrab 直接读取表格结构，导出干净的 CSV 或 XLSX 数据——零复制错误，零格式丢失。

| 优势 | 说明 |
|------|------|
| 📊 **自动识别** | 扫描页面所有原生 `<table>` 与 ARIA/div 网格（role=grid/treegrid/table），显示行×列数 |
| 📗 **Excel 导出** | 真实合并单元格、样式/冻结表头、自动列宽，一表一 Sheet |
| 🔗 **合并单元格** | 正确处理 rowspan/colspan，保留表格结构 |

| 👁️ **导出前预览** | 先查看表格内容，按需取消不需要的列 |
| 📋 **TSV / Markdown 复制** | 直接粘贴到 Excel、Notion、GitHub 或聊天工具 |
| 📦 **批量导出** | 单表/多选/全表一键导出 |
| 🔤 **无乱码** | UTF-8 BOM 编码修复中文乱码 |

## 安装方法

1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 开启**开发者模式**
3. 点击**加载已解压的扩展程序**，选择项目文件夹

---

## 使用方法

1. 访问任何含表格或 ARIA/div 数据网格的网页
2. 点击 **TableGrab** 图标
3. 表格自动识别，显示行×列信息
4. 悬停高亮，勾选要导出的表格；点**预览**可查看内容并选择列
5. 点击**导出全部**或**导出选中**，或使用**复制 TSV / Markdown**
6. CSV 或 XLSX 文件自动下载

---

## 已知限制

- div 网格需暴露 ARIA 角色（`grid`/`treegrid`/`table` 及行/单元格角色），如 MUI DataGrid、AG Grid；Canvas 渲染或没有可访问行/单元格结构的 div 网格无法读取
- 分页或虚拟滚动的表格只能导出当前 DOM 中已渲染的行和列
- 跨域 iframe 表格无法访问（浏览器安全限制）
- 复杂动态加密表格可能无法解析
- 超过 32,767 字符的单元格会截断，以符合 Excel 单元格上限
