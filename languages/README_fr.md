# TableGrab
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | Français

Une extension légère qui extrait les tableaux HTML de toute page web et les exporte en CSV.

> Chromium · Manifest V3 · Permissions minimales · Local Only

---

## Pourquoi TableGrab ?

Avez-vous déjà essayé de copier un tableau d'un site web et obtenu un format désordonné ? TableGrab lit la structure HTML directement et exporte des données CSV propres.

| Avantage | Détail |
|----------|--------|
| 📊 **Auto-détection** | Scanne tous les tableaux HTML de la page |
| 🔗 **Cellules fusionnées** | Support rowspan/colspan |
| 📦 **Export par lot** | Un tableau, sélectionnés ou tous |
| 🔤 **Pas de caractères** | UTF-8 BOM pour les caractères CJK |
| ⚡ **Un clic** | Téléchargement instantané |
| 🔒 **Privé** | Seulement3 permissions |

---

## Fonctionnalités

- Détection automatique des tableaux HTML
- Cellules fusionnées (rowspan/colspan)
- Export unique/sélectionné/par lot
- Encodage UTF-8 BOM
- Surbrillance au survol
- Nom de fichier automatique

## Installation

1. Ouvrez `chrome://extensions/`
2. Activez le **Mode développeur**
3. Cliquez sur **Charger l'extension non empaquetée**

---

## Confidentialité

- ✅ Zéro upload · Pas d'analytics · Pas de requêtes réseau
- ✅ Seulement `activeTab` + `scripting` + `downloads`

---

## Avis de droit d'auteur

Cette extension ne fait que lire les structures de tableaux HTML déjà chargées sur les pages web et les convertir au format CSV pour téléchargement local.
