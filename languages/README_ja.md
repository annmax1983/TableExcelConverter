# TableGrab

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

任意のWebページからHTMLテーブルを抽出し、ワンクリックでCSVファイルとしてエクスポートできる軽量ブラウザ拡張機能です。

> Chromium系ブラウザ対応 · Manifest V3 · 最小限の権限 · プライバシー最優先

---

## TableGrabの特長

政府サイトやデータプラットフォームからテーブルをコピーしようとして、フォーマットが崩れた経験はありませんか？TableGrabはHTMLテーブル構造を直接読み取り、クリーンなCSVデータをエクスポートします — コピーペーストのミスやフォーマットの損失はありません。

| 特長 | 詳細 |
|-----------|--------|
| 📊 **自動検出** | ページ上のすべてのHTMLテーブルをスキャンし、行×列数を表示 |
| 🔗 **結合セル対応** | rowspan/colspanを正しく処理し、テーブル構造を保持 |
| 📦 **バッチエクスポート** | 単一、選択、またはすべてのテーブルを一括エクスポート |
| 🔤 **文字化けなし** | UTF-8 BOMエンコーディングでCJK文字の問題を修正 |
| ⚡ **ワンクリック** | 即座にダウンロード、ページ再読み込み不要 |
| 🔒 **プライベート** | 最小限の権限、テーブルデータはアップロードされません |

## インストール

1. `chrome://extensions/`または`edge://extensions/`を開きます
2. **デベロッパーモード**を有効にします
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、プロジェクトフォルダを選択します

---

## 使い方

1. HTMLテーブルのある任意のページにアクセスします
2. **TableGrab**アイコンをクリックします
3. テーブルが自動検出され、行×列情報とともに一覧表示されます
4. ホバーでハイライト、チェックで選択します
5. **すべてエクスポート**または**選択分をエクスポート**をクリックします
6. CSVファイルが自動的にダウンロードされます

---

## 既知の制限事項

- HTML `<table>`要素のみサポート — 画像テーブル、Canvasテーブル、バーチャルJSテーブルには対応していません
- クロスオリジンiframeのテーブルにはアクセスできません（ブラウザのセキュリティ制限）
- 複雑に動的暗号化されたテーブルは正しく解析できない場合があります

## プライバシー

- ✅ テーブルデータやページコンテンツがアップロードされることはありません — 解析とCSVエクスポートはローカルで実行されます
- ✅ アナリティクス、トラッキングなし
- ✅ 権限：`activeTab`＋`scripting`＋`downloads`＋`storage`、および公式ライセンスサーバーへのホストアクセス
- ✅ `storage`はライセンスキーと設定にのみ使用 — 閲覧データは保存されません
- 🔑 Premiumライセンスの有効化/検証では公式ライセンスサーバー（api.annmax1983.com）にのみ接続 — テーブルデータは送信されません
