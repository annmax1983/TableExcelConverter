---

## なぜ TableGrab？

ウェブサイトからテーブルをコピーしようとして、フォーマットが崩れたことはありませんか？TableGrabはHTMLテーブル構造を直接読み、クリーンなCSVデータをエクスポートします。

| 利点 | 詳細 |
|------|------|
| 📊 **自動検出** | ページの全HTMLテーブルをスキャン |
| 🔗 **結合セル対応** | rowspan/colspanサポート |
| 📦 **一括エクスポート** | 単一/選択/全て |
| 🔤 **文字化けなし** | UTF-8 BOMでCJK文字修正 |
| ⚡ **ワンクリック** | 即座にダウンロード |
| 🔒 **プライベート** | 最小限の権限、テーブルデータはアップロードしません |

## プライバシー

- ✅ テーブルデータやページコンテンツはアップロードされません — 解析とCSV出力はローカルで実行
- ✅ 分析なし・トラッキングなし
- ✅ 権限：`activeTab` + `scripting` + `downloads` + `storage`、および公式ライセンスサーバーへのホストアクセス
- ✅ `storage` はライセンスと設定のみに使用
- 🔑 プレミアムライセンスのアクティベーション/検証は公式ライセンスサーバー（api.annmax1983.com）にのみ接続 — テーブルデータは一切送信されません

## 著作権免責事項

本拡張機能は、ウェブページ上に既に読み込まれたHTMLテーブル構造を読み取り、CSV形式に変換してローカルダウンロードするのみです。すべてのテーブルデータとウェブページコンテンツの著作権は元のウェブサイトに帰属します。
