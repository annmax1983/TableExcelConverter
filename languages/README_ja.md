# TableGrab
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

あらゆるウェブページからHTMLテーブルを抽出し、CSVとしてエクスポートする軽量ブラウザ拡張機能。

> Chromium · Manifest V3 · 最小権限 · 完全ローカル

---

## なぜ TableGrab？

ウェブサイトからテーブルをコピーしようとして、フォーマットが崩れたことはありませんか？TableGrabはHTMLテーブル構造を直接読み、クリーンなCSVデータをエクスポートします。

| 利点 | 詳細 |
|------|------|
| 📊 **自動検出** | ページの全HTMLテーブルをスキャン |
| 🔗 **結合セル対応** | rowspan/colspanサポート |
| 📦 **一括エクスポート** | 単一/選択/全て |
| 🔤 **文字化けなし** | UTF-8 BOMでCJK文字修正 |
| ⚡ **ワンクリック** | 即座にダウンロード |
| 🔒 **プライベート** | 権限3つのみ、ゼロアップロード |

---

## 機能

- HTMLテーブル自動検出
- 結合セル（rowspan/colspan）対応
- 単一/複数/一括エクスポート
- UTF-8 BOMエンコーディング
- ホバーでテーブルハイライト
- 自動ファイル名生成

## インストール

1. `chrome://extensions/` を開く
2. **デベロッパーモード**を有効にする
3. **パッケージ化されていない拡張機能を読み込む**

---

## プライバシー

- ✅ データアップロードなし · 分析なし · ネットワークリクエストなし
- ✅ `activeTab` + `scripting` + `downloads` 権限のみ

---

## 著作権免責事項

本拡張機能は、ウェブページ上に既に読み込まれたHTMLテーブル構造を読み取り、CSV形式に変換してローカルダウンロードするのみです。すべてのテーブルデータとウェブページコンテンツの著作権は元のウェブサイトに帰属します。
