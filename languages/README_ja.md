# TableGrab

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

任意のWebページからネイティブHTMLテーブルとARIA/divデータグリッドを抽出し、ワンクリックでCSVまたはExcel（XLSX）ファイルとしてエクスポートできる軽量ブラウザ拡張機能です。

> Chromium系ブラウザ対応 · Manifest V3 · 最小限の権限 · プライバシー最優先

---

## TableGrabの特長

政府サイトやデータプラットフォームからテーブルをコピーしようとして、フォーマットが崩れた経験はありませんか？TableGrabはテーブル構造を直接読み取り、クリーンなCSV/XLSXデータをエクスポートします — コピーペーストのミスやフォーマットの損失はありません。

| 特長 | 詳細 |
|-----------|--------|
| 📊 **自動検出** | ページ上のすべてのネイティブテーブルとARIA/divグリッド（role=grid/treegrid/table）をスキャンし、行×列数を表示 |
| 📗 **Excelエクスポート** | 実際の結合セル、スタイル付き/固定ヘッダー、自動列幅、1テーブル1シート |
| 🔗 **結合セル対応** | rowspan/colspanを正しく処理し、テーブル構造を保持 |
| 🧱 **divグリッド** | MUI DataGrid / AG Gridなどのグリッドを読み取り、固定列のクローンを統合 |
| 👁️ **エクスポート前プレビュー** | エクスポート前に内容を確認し、不要な列を外せます |
| 📋 **TSV / Markdownコピー** | Excel、Notion、GitHub、チャットにそのまま貼り付け |
| 📦 **バッチエクスポート** | 単一、選択、またはすべてのテーブルを一括エクスポート |
| 🔤 **文字化けなし** | UTF-8 BOMエンコーディングでCJK文字の問題を修正 |
| ⚡ **ワンクリック** | 即座にダウンロード、ページ再読み込み不要 |
| 🔒 **プライベート** | 最小限の権限、テーブルデータはアップロードされません |

## インストール

1. `chrome://extensions/`または`edge://extensions/`を開きます
2. **デベロッパーモード**を有効にします
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、プロジェクトフォルダを選択します

---

## 使い方

1. テーブルまたはARIA/divデータグリッドのある任意のページにアクセスします
2. **TableGrab**アイコンをクリックします
3. テーブルが自動検出され、行×列情報とともに一覧表示されます
4. ホバーでハイライト、チェックで選択します。**プレビュー**で内容を確認し列を選べます
5. **すべてエクスポート**または**選択分をエクスポート**、あるいは**TSV / Markdownとしてコピー**をクリックします
6. CSVまたはXLSXファイルが自動的にダウンロードされます

---

## 既知の制限事項

- divグリッドはARIAロール（`grid`/`treegrid`/`table`と行/セルロール）を公開している場合に対応します（MUI DataGrid、AG Gridなど）。Canvas描画や、アクセシブルな行/セル構造を持たないdivグリッドは読み取れません
- ページネーションや仮想スクロールのテーブルは、現在DOMにある行と列のみエクスポートされます
- クロスオリジンiframeのテーブルにはアクセスできません（ブラウザのセキュリティ制限）
- 複雑に動的暗号化されたテーブルは正しく解析できない場合があります
- 32,767文字を超えるセルはExcelの上限に合わせて切り詰められます

## プライバシー

- ✅ テーブルデータやページコンテンツがアップロードされることはありません — 解析とCSV/XLSXエクスポートはローカルで実行されます
