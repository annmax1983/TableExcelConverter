Privacy Policy

TableGrab · Last updated: July 2026

TL;DR: TableGrab does not collect or transmit your table data or page content. All table parsing and CSV export happen locally in your browser. The only network connection is to the official license server when you activate or validate a premium license, which receives a random install identifier and basic browser metadata (see section 1) for license validation only.

1. Data Collection

TableGrab does not collect personal information, browsing data, or usage analytics. When you activate or validate a premium license, a random install identifier plus basic browser metadata (browser name/version, language, timezone, and user agent) is sent to the official license server solely for license validation.

2. How It Works

  • Scan — Reads HTML table elements from the current page
  • Export — Converts table data to CSV and triggers local download
  • License — When you activate or validate a premium license, connects to the official license server to check your key. No table data is ever transmitted.

3. Permissions

activeTab — Access current tab to scan tables. scripting — Inject table parser. downloads — Save CSV file locally. storage — Store your license key locally. Host access to api.annmax1983.com — Activate/validate premium license.

4. Third-Party Services

TableGrab connects only to the official license server at api.annmax1983.com, and only when you activate or validate a premium license. Table data and page content are never transmitted to any server.
