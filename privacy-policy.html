Privacy Policy

TableGrab · Last updated: July 2026

TL;DR: TableGrab does NOT collect, store, or transmit any of your personal data. All table processing happens fully locally in your browser.

1. Data Collection

TableGrab does not collect any personal information, browsing data, or usage analytics.

2. How It Works

  • Scan — Reads HTML table elements from the current page
  • Export — Converts table data to CSV and triggers local download
  • No Network — Zero network requests, all processing is local

3. Permissions

activeTab — Access current tab to scan tables. scripting — Inject table parser. downloads — Save CSV file locally.

4. Third-Party Services

TableGrab does not connect to any third-party services, APIs, or external servers.

5. Contact

Questions? Open an issue on our GitHub.
