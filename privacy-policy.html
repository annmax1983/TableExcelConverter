TableGrab Privacy Policy

TableGrab does not collect or transmit your table data or page content. All table parsing and CSV export happen locally in your browser. The only network connection is to the official license server when you activate or validate a premium license, which receives a random install identifier and basic browser metadata (see section 1) for license validation only.

01Data Collection

TableGrab does not collect personal information, browsing data, or usage analytics. When you activate or validate a premium license, a random install identifier plus basic browser metadata (browser name/version, language, timezone, and user agent) is sent to the official license server solely for license validation.

02How It Works

  • Scan — Reads HTML table elements from the current page
  • Export — Converts table data to CSV and triggers local download
  • License — When you activate or validate a premium license, connects to the official license server to check your key. No table data is ever transmitted.

03Permissions

activeTab — Access current tab to scan tables. scripting — Inject table parser. downloads — Save CSV file locally. storage — Store your license key locally. Host access to api.annmax1983.com — Activate/validate premium license.

04Third-Party Services

TableGrab connects only to the official licence server at api.annmax1983.com, and only when you activate or validate a premium licence. The request contains your licence key, a random install identifier, the plugin identifier and basic browser metadata (browser name and major version, interface language, time zone and user-agent string). Table data and page content are never transmitted to any server. Our licence server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

05Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them.

06Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.

07Contact

Questions about this policy? Email support@annmax1983.com or open an issue on GitHub.
