TableGrab is a web table to Excel converter for Chrome and Edge. Open it on a page full of data, and it finds the native HTML tables and the ARIA/div data grids, then exports exactly what you choose as a clean Excel workbook (XLSX) or a CSV file. Merged cells, multi-row headers and pinned grid columns are rebuilt instead of copied as loose text. Preview the rows, untick columns you do not need, and download. No account, no ads and no analytics; the free tier exports up to five tables per page.

01

Everything it does

The core features at a glance.

01

Finds every data table on the page automatically and lists it with its row × column count.

02

Handles native HTML tables and ARIA/div grids, including MUI DataGrid and AG Grid layouts.

03

Rebuilds merged cells from row and column spans, so headers and grouped rows keep their shape.

04

Exports a real Excel workbook with one sheet per selected table, styled and frozen header rows, and auto-sized columns.

05

Exports CSV with UTF-8 BOM switched on by default, so Chinese and other CJK characters stay readable.

06

Shows a scrollable preview of the first 50 rows before you export, with a checkbox for every column.

Also included

  • Remembers your column selection per table, so a wide report can be trimmed once and exported the same way again.
  • Copies the table as TSV or Markdown in one click, ready for Excel, Notion, GitHub or a chat window.
  • Reassembles split header and body tables used by Element Plus and Ant Design, instead of exporting "Column 1, Column 2".
  • Folds the duplicate pinned-column copies of virtualised grids back into one table.
  • Optional hidden tables, footer and totals rows, whitespace cleanup, and a save-location prompt for every file.
  • Smart file names combine the page title, the table count and a timestamp.

02

Free vs Premium

The free tier is a complete tool, not a trial. Premium is optional.

Free

automatic detection, native tables and ARIA/div grids, merged cells, split-header repair, XLSX and CSV export, preview, column selection, TSV and Markdown copy, multi-select and batch export, UTF-8 BOM, whitespace cleanup, hidden-table and footer options, save-location prompt, highlighting and smart file names — for up to five tables per page. Tables beyond the fifth are listed but locked.

Premium

removes the five-table limit, so every table on the page can be exported. One licence key activates on two browsers, and removing the licence from one browser frees that slot again.

The licence is optional. Everything except the table-count limit is free. Premium keeps working offline and asks the licence server for a check about every two hours; if the server cannot be reached, you are not locked out of the extension.

Private by design

Your data stays on your device. No account, no analytics, no tracking. Read exactly what is stored and when the extension uses the network.
